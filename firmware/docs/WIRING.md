# SafeBand v2 — схема подключения (текстом)

Пины соответствуют реальной пайке платы: SIM800L на GPIO5/6, GPS на GPIO7.
Картинка: [`wiring_v2.png`](wiring_v2.png).

## Распределение пинов ESP32-C3 Super Mini

| GPIO | Что подключено | Направление |
|---|---|---|
| GPIO0 | SDA — MPU6050 + MAX30102 (общая шина I2C) | ↔ |
| GPIO1 | SCL — MPU6050 + MAX30102 | → |
| GPIO2 | INMP441 SCK | → |
| GPIO3 | INMP441 WS | → |
| GPIO4 | INMP441 SD | ← |
| GPIO5 | SIM800L TXD (RX у ESP) | ← |
| GPIO6 | SIM800L RXD (TX у ESP) через делитель 10к/20к | → |
| GPIO7 | GPS NEO-6M TX | ← |
| GPIO8 | LED на плате — **не занимать** | — |
| GPIO9 | кнопка BOOT — **не занимать** | — |
| GPIO10 | Буззер (+) | → |
| GPIO20 | Кнопка SOS (второй вывод на GND) | ← |
| GPIO21 | Вибромотор: 1 кОм → база NPN | → |
| 3.3 | питание датчиков (линия **3V3**) | выход |
| 5V | вход от MT3608 (линия **5V**) | вход |
| G | общая земля (**GND**) | — |

## Провод за проводом

```
MPU6050 (GY-521)
  VCC  -> 3V3
  GND  -> GND
  SDA  -> GPIO0
  SCL  -> GPIO1
  XDA, XCL, AD0, INT -> не подключать

MAX30102
  VIN  -> 3V3
  GND  -> GND
  SDA  -> GPIO0   (вместе с MPU6050)
  SCL  -> GPIO1   (вместе с MPU6050)
  INT  -> не подключать

INMP441
  VDD  -> 3V3
  GND  -> GND
  L/R  -> GND
  SCK  -> GPIO2
  WS   -> GPIO3
  SD   -> GPIO4

SIM800L
  VCC  -> VBAT (батарея после выключателя) + конденсатор 1000 мкФ 16 В вплотную к пинам
  GND  -> GND (короткий толстый провод)
  TXD  -> GPIO5 напрямую
  RXD  <- GPIO6 через делитель:
            GPIO6 ---[10 кОм]---+--- SIM800L RXD
                                |
                             [20 кОм]
                                |
                               GND
  RST, NET, DTR, RING -> не подключать

GPS NEO-6M
  VCC  -> 5V
  GND  -> GND
  TX   -> GPIO7
  RX   -> не подключать

Вибромотор (через NPN-ключ S8050 / 2N2222)
  GPIO21 ---[1 кОм]--- База NPN
  Эмиттер NPN -> GND
  Коллектор NPN -> мотор (−)
  Мотор (+) -> 3V3
  Диод 1N4148 параллельно мотору: полоска (катод) к 3V3, анод к коллектору

Буззер
  (+) -> GPIO10
  (−) -> GND
  (если буззер громкий, > 20 мА — через такой же NPN-ключ, как вибромотор)

Кнопка SOS (без фиксации)
  вывод 1 -> GPIO20
  вывод 2 -> GND
  (подтяжка внутренняя, резистор не нужен)
```

## Питание

```
Li-Po 3.7 В (+) -> TP4056 B+
Li-Po 3.7 В (−) -> TP4056 B−
TP4056 OUT+ -> выключатель -> VBAT
VBAT -> SIM800L VCC   (+ 1000 мкФ)
VBAT -> MT3608 VIN+
MT3608 VOUT+ (выставить 5.0 В!) -> ESP32 5V, GPS VCC
TP4056 OUT−, MT3608 VIN−, MT3608 VOUT− -> GND
Все GND (батарея, TP4056, MT3608, ESP32, все модули) -> в одну общую точку
USB-C на TP4056 = зарядка браслета
```

## Важно

1. MT3608: сначала подключить только к батарее, выставить 5.0 В мультиметром, потом к ESP32.
2. SIM800L — только от VBAT (3.7–4.2 В). От 5 В и от пина 3.3 платы — нельзя.
3. Прошивать ESP32 по USB при **выключенном** выключателе.
4. GPIO21 при старте платы на долю секунды дёргается (загрузчик пишет туда лог) — вибромотор этого не заметит.
5. GPIO8 и GPIO9 не занимать: от них зависит загрузка платы.
