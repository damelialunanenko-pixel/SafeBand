# SafeBand — финальная версия браслета: схема подключения (текстом)

За основу взята собранная плата: SIM800L на GPIO5/6, GPS на GPIO7, кнопка SOS на GPIO10, буззер на GPIO20,
питание ESP32 через повышающий MT3608 (5.0 В) с выключателем. К ней добавлены MAX30102, INMP441 и вибромотор
на свободные пины. Картинка: [`wiring_v2.png`](wiring_v2.png).

## Распределение пинов ESP32-C3 Super Mini

| GPIO | Что подключено | Статус |
|---|---|---|
| GPIO0 | SDA — MPU6050 + MAX30102 (общая шина I2C) | MPU уже есть, MAX30102 добавить |
| GPIO1 | SCL — MPU6050 + MAX30102 | MPU уже есть, MAX30102 добавить |
| GPIO2 | INMP441 SCK | **новое** |
| GPIO3 | INMP441 WS | **новое** |
| GPIO4 | INMP441 SD | **новое** |
| GPIO5 | SIM800L TXD (RX у ESP) | как на плате |
| GPIO6 | SIM800L RXD через делитель 10 кОм / 20 кОм | как на плате |
| GPIO7 | GPS NEO-6M TX | как на плате |
| GPIO8 | LED на плате — **не занимать** | — |
| GPIO9 | кнопка BOOT — **не занимать** | — |
| GPIO10 | Кнопка SOS (вторая ножка на GND) | как на плате |
| GPIO20 | Буззер (+) | как на плате |
| GPIO21 | Вибромотор: 1 кОм → база NPN | **новое** |
| 3.3 | шина **+3.3V**: MPU6050, MAX30102, INMP441, GPS, вибромотор | выход |
| 5V | от MT3608 VOUT+ (**5.0 В**) | вход |
| G | общая земля **GND** | — |

## Провод за проводом

```
MPU6050 (GY-521)                          [уже на плате]
  VCC  -> 3V3
  GND  -> GND
  SDA  -> GPIO0
  SCL  -> GPIO1
  XDA, XCL, AD0, INT -> не подключать

GPS NEO-6M                                [уже на плате]
  VCC  -> 3V3
  GND  -> GND
  TX   -> GPIO7
  RX   -> не подключать

SIM800L                                   [уже на плате]
  VCC  -> +BAT, конденсатор 1000 мкФ 16 В между VCC и GND (полоска «−» на GND)
  GND  -> GND
  TXD  -> GPIO5 напрямую
  RXD  <- GPIO6 через делитель:
            GPIO6 ---[10 кОм]---+--- SIM800L RXD
                                |
                             [20 кОм]
                                |
                               GND
  NET, RST, DTR, RING -> не подключать

Буззер                                    [уже на плате]
  (+) -> GPIO20
  (−) -> GND

Кнопка SOS (без фиксации)                 [уже на плате]
  одна ножка -> GPIO10, диагональная ножка -> GND
  (подтяжка внутренняя, резистор не нужен)

MAX30102                                  [НОВОЕ]
  VIN  -> 3V3
  GND  -> GND
  SDA  -> GPIO0   (к той же точке, что SDA MPU6050)
  SCL  -> GPIO1   (к той же точке, что SCL MPU6050)
  INT  -> не подключать

INMP441                                   [НОВОЕ]
  VDD  -> 3V3
  GND  -> GND
  L/R  -> GND
  SCK  -> GPIO2
  WS   -> GPIO3
  SD   -> GPIO4

Вибромотор через NPN-ключ S8050 / 2N2222  [НОВОЕ]
  GPIO21 ---[1 кОм]--- База NPN
  Эмиттер NPN   -> GND
  Коллектор NPN -> мотор (−)
  Мотор (+)     -> 3V3
  Диод 1N4148 параллельно мотору: полоска (катод) к 3V3, анод к коллектору
```

## Питание

```
Li-Po 3.7 В 1000 мАч (+) -> TP4056 B+
Li-Po 3.7 В 1000 мАч (−) -> TP4056 B−
TP4056 OUT+ -> выключатель -> шина +BAT
TP4056 OUT− -> GND
+BAT -> SIM800L VCC (+ конденсатор 1000 мкФ)
+BAT -> MT3608 VIN+
MT3608 VOUT+ (выставить 5.0 В!) -> пин 5V ESP32
MT3608 VIN−, VOUT− -> GND
ESP32 3.3 -> шина +3.3V (все датчики, GPS, вибромотор)
Все GND -> в одну общую точку
USB-C на TP4056 = зарядка браслета
```

## Важно

1. MT3608: сначала подключить только к батарее, мультиметром выставить 5.0 В, и только потом подключать к ESP32 (с завода он может выдавать 10–28 В).
2. SIM800L питается только от +BAT (3.7–4.2 В). От 3.3 В платы он работать не будет.
3. Прошивать ESP32 по USB при **выключенном** выключателе, чтобы 5 В от USB и от MT3608 не встретились.
4. MAX30102 ставить окошком к коже. MPU6050 крепить жёстко к плате, подальше от вибромотора.
5. От стабилизатора 3.3 В теперь питаются GPS, три датчика и вибромотор: в сумме около 150–200 мА, для платы это нормально. Если ESP32 перезагружается в момент вибрации, мотор лучше питать от +BAT, а не от 3V3.
6. GPIO8 и GPIO9 не занимать: от них зависит загрузка платы.
7. При включении платы на GPIO20 и GPIO21 на долю секунды выводится служебный лог. Буззер может коротко щёлкнуть, это нормально.
